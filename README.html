🧾 EIB Assistant – RSU Tax Formatter

A browser-based tool that reads your RSU output spreadsheet and automatically generates rows in the exact format required by the Payroll Off cycle Payment EIB (134-column layout).

🚀 How to Use

  1. Download EIB_Assistant_Standalone.html and open it in Chrome or Edge
  2. Step 1 — Drop your output spreadsheet (.xlsx) onto the upload area
  3. Step 2 — Select an Employee ID and Transaction ID (or leave blank for all)
  4. Step 3 — Confirm the EIB settings (Batch ID, dates, Run Category, etc.)
  5. Step 4 — Click Export to Excel or Copy Rows and paste directly into your EIB

✅ Features

  • Exact 134-column EIB layout (Payroll Off cycle Payment v25.2)
  • Auto-detects Original, Deloitte, and QUESTIONS_ sheets
  • Maps state abbreviations → Payroll Authority Tax Codes (leading zeros preserved)
  • Generates TVRSU, NVRSU, W_SWW + W_CWCGW / W_TTWG / W_TXWG sub-lines per state
  • Skips state rows where all values are zero
  • Transaction ID written to Spreadsheet Key column
  • Bulk export — process every employee at once
  • Works fully offline — no server or install needed

About

RSU Tax EIB formatter — converts output spreadsheets into Workday-ready payroll rows.
